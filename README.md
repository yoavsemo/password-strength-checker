# Password Strength Checker

A command-line password strength checker written in Python.

The program checks whether a password:

- Is at least eight characters long
- Contains uppercase and lowercase letters
- Contains a number
- Contains a special character
- Contains the username
- Contains adjacent repeated characters
- Contains consecutive numbers

It then classifies the password as weak, moderate, or strong.

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal inside the project folder.
4. Run:

```bash
python password_checker.py
